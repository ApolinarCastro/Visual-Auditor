# Knowledge-to-Skill Distillation

## Mission
Convert books, documentation, repositories, incidents, postmortems, and verified project experience into small reusable skills without turning unverified ideas into architecture.

## Source priority
Project evidence/certified state -> official documentation/standards -> books/research -> repositories -> community material.

## Pipeline
ACQUIRE -> CLASSIFY -> NORMALIZE -> TAG -> VALIDATE -> LINK -> DISTILL -> TEST -> PUBLISH -> VERSION.

## Knowledge types
PRINCIPLE; PATTERN; ANTI_PATTERN; PLAYBOOK; CHECKLIST; DECISION_RULE; SKILL; PROJECT_FACT.

## Validation gate
Trace project claims to evidence. Separate source statement from inference. Test whether the rule helps a real prior task. Reject duplicates. Prefer the smallest reusable unit. Mark uncertainty/staleness. Never modify core architecture merely because a source recommends a pattern.

## Learning loop
Problem -> Evidence -> Root cause -> Verified solution -> Pattern -> Skill candidate -> Reuse -> Revalidation -> Versioned knowledge.

## Stop
PASS when a compact reusable skill has provenance, activation, and validation. NO_SKILL when material lacks demonstrated operational value. BLOCKED when evidence is insufficient or contradictory.
